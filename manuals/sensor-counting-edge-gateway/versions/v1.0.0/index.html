Sensor Counting Edge Gateway

Operator guide for monitoring counts, checking update delivery and understanding the web UI. Use this manual when working with the system in daily operation.

TDC-XPhotoelectric sensor

Purpose of the system

The Sensor Counting Edge Gateway reads counting values from field sensors, links them to the current active production session, and sends regular updates to the business server. It also provides a simple local dashboard for operators.

Open the UI

Use a supported web browser and open the dashboard URLs.

Main pages
/dashboard/operations
/dashboard/update-history
/dashboard/system-log

Normal operator scope

Operators monitor counts, review update results, export CSV files and check system health. Daily operation does not require editing sensor or line settings.

Important note

Line sensor configuration is prepared once in the beginning. If a line is not counting correctly, use the troubleshooting page and contact support instead of changing settings.

In short: sensor pulses are counted in the WISE device, the edge gateway checks the latest pending record from the server, sends update records every configured interval (default 5 minutes), and automatically handles session changes.

What operators usually do

  1. Open the Operations page and confirm the server connection and line status.
  2. Watch the current count, active session and queue status for each line.
  3. Review the Recent update history page when you want to confirm submitted updates.
  4. Review the System log page when a warning or error needs attention.
  5. Download CSV files from the history or log pages when you need to share records with support.

Expected operator result

  • Line is ONLINE.
  • Current hardware count increases when products pass the sensor.
  • Update queue normally stays low or empty.
  • Recent update history shows successful updates.

When to ask for support

  • WISE stays offline.
  • Update queue keeps growing.
  • System log shows repeated errors.
  • Count does not increase although the sensor is triggered.
