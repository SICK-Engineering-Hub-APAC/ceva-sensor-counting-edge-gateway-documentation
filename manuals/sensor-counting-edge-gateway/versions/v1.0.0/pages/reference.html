Function Typical default

Status meanings

Status Meaning
ONLINE The gateway can communicate with the WISE device.
OFFLINE The WISE device is unreachable or not responding.
ACTIVE The line is working with an active session and record.
IDLE No active session is currently bound.
Transitioning / Resetting The line is moving from one session to another and resetting its counter.

Typical field meanings

Field Meaning
Session Current session ID used by the line.
Record Current server record ID that receives updates.
Balance Target quantity for the current record.
Left Remaining quantity to be completed.
Current hardware count Latest WISE counter reading.
Queue Number of queued updates for the line.
Snapshots Local count snapshots waiting to be bound or processed.

WISE device note

Counter mode

Each installed WISE-4060/WISE-4051 device is commissioned so the selected line channel works as a counter input. Operators normally do not need to open the WISE device web page.

Operator responsibility

During normal operation, do not change WISE network or counter settings. If a line does not count correctly, use the dashboard and exported logs for troubleshooting, then contact support.
